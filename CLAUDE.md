# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repo is

A tiny practice repo for shipping a first pull request with Claude Code. It exists
solely to practice the GitHub workflow: branch, commit, push, and open a pull
request against it. There is no application code, build system, or test suite —
just a README and a LICENSE.

## Repository structure

- `README.md` — describes the repo's purpose and usage
- `LICENSE` — MIT License

## Workflow notes

- Remote: `origin` → `ericksalec/first-pr-practice` on GitHub
- Branches: `main` (default) and `add-license`
- Since this repo has no code, working here means practicing the PR mechanics
  themselves (branching, committing, pushing, opening PRs) rather than writing
  or testing software. There are no build, lint, or test commands to run.
